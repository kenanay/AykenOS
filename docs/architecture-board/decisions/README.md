# Architecture Board Decisions

Bu dizin freeze dönemindeki mimari karar kayıtlarının resmi arşividir.

## Rules

1. Her karar ayrı dosya olmalı.
2. Karar dosyası RFC veya Waiver linki içermeli.
3. Karar sonucu açık olmalı: `approved | rejected | deferred`.
4. Karar tarihi ve imza (reviewer listesi) zorunlu.

## File Naming

`YYYYMMDD-<decision-title>.md`
