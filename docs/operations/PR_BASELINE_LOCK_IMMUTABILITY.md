# ci(perf): baseline lock immutability enforcement

## Purpose

This PR enforces baseline lock immutability in pull requests, preventing accidental baseline drift and ensuring only authorized workflows can modify baseline files.

## Changes

### 1. Baseline Lock Immutability Check

Added PR guard to `scripts/ci/gate_performance.sh`:
- Detects if baseline lock file was modified in PR
- Fails with `baseline lock immutability violation` if mutation detected
- Only authorized workflows can bypass via `PERF_ALLOW_BASELINE_LOCK_MUTATION=1`

### 2. Authorized Workflow Bypass

Updated `.github/workflows/perf-baseline-init.yml`:
- Added `PERF_ALLOW_BASELINE_LOCK_MUTATION: "1"` to env
- Allows baseline-init workflow to write baseline lock files
- Maintains fail-closed enforcement for all other contexts

### 3. Policy Documentation

Updated `docs/operations/PERF_BASELINE_POLICY.md`:
- Added "Baseline Lock Immutability" section
- Documents protected files: `perf-baseline.lock.json`, `abi-baseline.lock.json`
- Explains enforcement mechanism and authorized mutation paths
- Clarifies rationale: prevents drift, inflation, manual editing, split renewal

## Protected Files

- `scripts/ci/perf-baseline.lock.json` (performance baseline) - **enforced**
- `scripts/ci/abi-baseline.lock.json` (ABI baseline) - **future enforcement**

**Note:** This PR enforces immutability only for the performance baseline lock. ABI baseline lock enforcement will be added in a future phase.

## Enforcement Logic

```bash
# PR context check
if [[ "${GITHUB_EVENT_NAME}" == "pull_request" && "${PERF_ALLOW_BASELINE_LOCK_MUTATION}" != "1" ]]; then
  # Check if baseline lock mutated
  if git diff origin/main...HEAD -- "${BASELINE_FILE}" | grep -q .; then
    echo "performance: FAIL (baseline lock immutability violation)"
    exit 2
  fi
fi
```

## Rationale

Baseline lock immutability prevents:
- **Accidental drift**: Feature PRs can't accidentally modify baseline
- **Baseline inflation**: Can't hide regressions by updating baseline
- **Manual editing**: Baseline must be generated by authorized workflow
- **Split renewal**: Code change and baseline update must be in same PR

## Authorized Mutation Paths

Only these workflows can write baseline locks:
- `perf-baseline-init.yml` (performance baseline renewal)
- Future: `abi-baseline-init.yml` (ABI baseline renewal)
