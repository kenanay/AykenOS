AykenOS Kurulum Rehberi

Lokal repo gerçeklerine göre doğrulanmış kurulum, build ve gate doğrulama akışı.

Kurulum Öncesi Hazırlık

Önemli: Bu rehber, geliştirme ortamı kurulumu içindir. Faz durumu 2026-02-21 itibarıyla Phase 4.5 stabilization olarak izlenmektedir.

Sistem Gereksinimleri

Minimum

  • x86_64 geliştirme ortamı
  • 4GB RAM
  • 20GB boş disk
  • Git + shell araçları
  • QEMU (runtime test için)

Önerilen

  • 8GB+ RAM
  • SSD depolama
  • clang + ld.lld + nasm
  • make ve script araçları
  • Rust toolchain (userspace geliştirme için)

Platform Durumu

Platform Durum Not
macOS Destekli Homebrew ile araç kurulumu yaygın akış
Linux (Ubuntu/Debian/Fedora) Destekli Paket yöneticisi ile bağımlılık kurulumu
Windows (WSL2) Destekli PowerShell + WSL2 kombinasyonu önerilir
Windows Native Kısmi Script ve toolchain uyumu proje sürümüne göre değişebilir

Geliştirme Araçları Kurulumu

1

Repo İçi Setup Akışı

Projede önerilen ilk adım, setup hedefini çalıştırmaktır.

make setup

# Alternatif doğrudan script
./setup.sh
# veya Windows tarafı
./setup.ps1
2

Bağımlılıkları Kurma

make install-deps paket yöneticisine göre araçları yüklemeyi dener.

macOS (örnek)

brew install qemu nasm llvm

Ubuntu/Debian (örnek)

sudo apt update
sudo apt install -y gcc-multilib nasm clang lld make qemu-system-x86

Fedora/RHEL (örnek)

sudo dnf install -y gcc nasm clang lld make qemu-system-x86
3

Toolchain Doğrulama

make validate-toolchain

# veya doğrudan
./tools/validation/validate_toolchain.sh --skip-qemu

AykenOS Kaynak Kodunu İndirme

1

Repository Klonlama

git clone https://github.com/kenanay/AykenOS.git
cd AykenOS
git status
2

Opsiyonel Submodule Güncelleme

git submodule update --init --recursive

Bu adım, projeye bağlı alt modüller kullanılıyorsa önerilir.

Otomatik Kurulum

Önerilen Yol

Önce make setup, ardından build/validate adımlarına geçmek en güvenli başlangıçtır.

1

Setup

make setup
make install-deps
2

Temel Doğrulama

make validate-toolchain
make check-deps

Manuel Kurulum

İleri Seviye: Setup akışı dışına çıkmanız gerekirse aşağıdaki adımlarla manuel ilerleyebilirsiniz.
1

Temel Derleme Araçları

clang --version
ld.lld --version
nasm -v
qemu-system-x86_64 --version
2

Opsiyonel Rust Kurulumu (Userspace)

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env
rustc --version
3

Path ve Ortam Kontrolü

which clang
which ld.lld
which nasm
which qemu-system-x86_64

İlk Build ve Test

1

Build

make clean
make all
make efi-img
2

QEMU Çalıştırma

make run

# Alternatif doğrulama akışı
make validate-qemu
3

Tam Doğrulama

make validate

# Build + qemu + toolchain birleşik akış
make validate-full

Anayasal Gate Kontrolü

Pratik Gate Seti

Phase 4.5 için günlük geliştirme akışında aşağıdaki kapılar özellikle önemlidir.

1

Hijyen ve ABI

make ci-gate-hygiene
make ci-gate-abi
2

Runtime ve Constitutional

make ci-gate-syscall-v2-runtime
make ci-gate-constitutional
3

Yerel Freeze Zinciri

make ci-freeze-local

# Tam zincir (strict)
make ci-freeze

Not: ci-freeze için AYKEN_SCHED_FALLBACK=0 zorunludur.

Sorun Giderme

Sık Karşılaşılan Durumlar

hygiene: FAIL (dirty_tracked)

# Kirli tracked dosyaları gör
git status --short

# Değişiklikleri commit et veya restore et
# sonra:
make ci-gate-hygiene

QEMU bulunamadı

which qemu-system-x86_64
make install-deps
make validate-qemu

Runtime gate sonucu inceleme

# Son run klasörünü aç
ls -1 evidence | tail

# Özet ve detay raporlar
cat evidence/run-*/reports/summary.json
cat evidence/run-*/gates/syscall-v2-runtime/report.json
Yardım Gerekiyor? Sorun yaşıyorsanız GitHub Issues üzerinden evidence run kimliği ile birlikte paylaşın.
