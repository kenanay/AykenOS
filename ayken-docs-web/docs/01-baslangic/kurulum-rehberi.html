AykenOS Kurulum Rehberi

AykenOS'u sisteminize kurmak için detaylı adım adım rehber.

Kurulum Öncesi Hazırlık

Önemli: AykenOS şu anda geliştirme aşamasındadır. Bu kurulum rehberi geliştirme ortamı kurulumu içindir.

Sistem Gereksinimleri

Minimum Gereksinimler

  • x86_64 veya ARM64 işlemci
  • 4GB RAM
  • 20GB boş disk alanı
  • UEFI desteği
  • İnternet bağlantısı

Önerilen Gereksinimler

  • 8GB+ RAM
  • 50GB+ SSD disk alanı
  • Multi-core işlemci
  • Virtualization desteği
  • Hızlı internet bağlantısı

Desteklenen Platformlar

Platform Durum Notlar
macOS (Intel/Apple Silicon) ✅ Tam Destek Homebrew ile kolay kurulum
Linux (Ubuntu/Debian) ✅ Tam Destek APT paket yöneticisi
Linux (Fedora/RHEL) ✅ Tam Destek DNF/YUM paket yöneticisi
Windows (WSL2) ✅ Tam Destek WSL2 Ubuntu önerilen
Windows (Native) 🚧 Kısmi Destek MSYS2/MinGW gerekli

Geliştirme Araçları Kurulumu

1

Rust Toolchain Kurulumu

AykenOS Rust ile geliştirildiği için Rust toolchain'i kurmanız gerekir.

macOS ve Linux:

# Rust kurulumu
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Shell'i yeniden başlatın veya:
source ~/.cargo/env

# Rust versiyonunu kontrol edin
rustc --version

Windows (WSL2):

# WSL2 Ubuntu içinde
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env
Not: AykenOS minimum Rust 1.70+ gerektirir. rustup update ile güncelleyebilirsiniz.
2

Build Araçları Kurulumu

macOS:

# Xcode Command Line Tools
xcode-select --install

# Homebrew ile ek araçlar
brew install qemu nasm binutils

Ubuntu/Debian:

# Build essentials
sudo apt update
sudo apt install -y build-essential git curl

# AykenOS specific tools
sudo apt install -y qemu-system-x86 nasm binutils-dev
sudo apt install -y pkg-config libssl-dev

Fedora/RHEL:

# Development tools
sudo dnf groupinstall "Development Tools"
sudo dnf install git curl

# AykenOS specific tools
sudo dnf install qemu nasm binutils-devel
sudo dnf install pkg-config openssl-devel
3

QEMU Kurulumu ve Yapılandırması

AykenOS'u test etmek için QEMU sanal makine ortamı gereklidir.

# QEMU versiyonunu kontrol edin
qemu-system-x86_64 --version

# KVM desteğini kontrol edin (Linux)
lscpu | grep Virtualization
ls -la /dev/kvm
macOS Kullanıcıları: Apple Silicon Mac'lerde x86_64 emülasyonu yavaş olabilir. ARM64 desteği geliştirilmektedir.

AykenOS Kaynak Kodunu İndirme

1

Git Repository Klonlama

# Repository'yi klonlayın
git clone https://github.com/kenanay/AykenOS.git

# Dizine geçin
cd AykenOS

# Branch durumunu kontrol edin
git branch -a
git status
2

Submodule'ları Güncelleme

# Submodule'ları başlat ve güncelle
git submodule init
git submodule update --recursive

# Alternatif: tek komutla

Otomatik Kurulum

Hızlı Kurulum

AykenOS otomatik kurulum scriptleri ile hızlı kurulum yapabilirsiniz.

1

Kurulum Scriptini Çalıştırma

macOS ve Linux:

# Kurulum scriptini çalıştır
./setup.sh

# Veya executable yapıp çalıştır
chmod +x setup.sh
./setup.sh

Windows (PowerShell):

# PowerShell'i yönetici olarak açın
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# Kurulum scriptini çalıştır
.\setup.ps1
2

Kurulum Doğrulama

# Kurulum doğrulama scriptini çalıştır
./validate.sh

# Veya Windows'ta
.\validate.ps1

Bu script şunları kontrol eder:

  • Rust toolchain versiyonu
  • Gerekli build araçları
  • QEMU kurulumu
  • Environment variables

Manuel Kurulum

İleri Seviye: Otomatik kurulum çalışmıyorsa veya özel yapılandırma istiyorsanız manuel kurulum yapabilirsiniz.
1

Rust Target'ları Ekleme

# Bare metal target'ı ekle
rustup target add x86_64-unknown-none

# ARM64 target (gelecek için)
rustup target add aarch64-unknown-none

# WASM target (userspace için)
rustup target add wasm32-unknown-unknown
2

Cargo Tools Kurulumu

# Bootimage tool
cargo install bootimage

# Cargo-make (build automation)
cargo install cargo-make

# Cargo-watch (development)
cargo install cargo-watch
3

Environment Variables

# ~/.bashrc veya ~/.zshrc'ye ekleyin
export AYKEN_ROOT="$(pwd)"
export AYKEN_TARGET="x86_64-unknown-none"
export QEMU_SYSTEM="qemu-system-x86_64"

# Shell'i yeniden başlatın
source ~/.bashrc  # veya ~/.zshrc

İlk Build ve Test

1

Projeyi Build Etme

# Tüm projeyi build et
make build

# Veya cargo ile
cargo build --release
İlk Build: İlk build işlemi dependencies indirme nedeniyle uzun sürebilir (10-30 dakika).
2

QEMU'da Test Etme

# QEMU'da çalıştır
make qemu

# Debug modunda çalıştır
make qemu-debug

# Çıkmak için: Ctrl+A, X
3

Testleri Çalıştırma

# Unit testleri çalıştır
make test

# Integration testleri
make test-integration

# Tüm testler
make test-all

Anayasal Sistem Kurulumu

Anayasal Yönetişim

AykenOS'un en önemli özelliği olan anayasal sistem kurulumu.

1

Ayken CLI Kurulumu

# Ayken CLI'yi build et
cd ayken
cargo build --release

# PATH'e ekle (Linux/macOS)
export PATH="$PATH:$(pwd)/target/release"

# Kurulumu test et
ayken --version
2

İlk Anayasal Kontrol

# Projenin anayasal durumunu kontrol et
ayken check

# Detaylı rapor
ayken check --format ci

# Mimari sağlık skoru
ayken ahs check

Sorun Giderme

Sık Karşılaşılan Sorunlar

Rust Version Hatası

# Rust'ı güncelle
rustup update stable
rustup default stable

QEMU Bulunamadı

# QEMU yolunu kontrol et
which qemu-system-x86_64
export QEMU_SYSTEM="$(which qemu-system-x86_64)"

Build Hatası

# Cache'i temizle
cargo clean
make clean

# Yeniden build et
make build
Yardım Gerekiyor? Sorun yaşıyorsanız GitHub Issues sayfasından yardım isteyebilirsiniz.
