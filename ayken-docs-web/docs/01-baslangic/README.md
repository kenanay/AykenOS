# Başlangıç Dokümantasyonu

Bu bölüm AykenOS'a yeni başlayanlar için temel bilgileri içerir.

## İçerik

- **Hızlı Başlangıç** - AykenOS'u hızlıca tanımak ve çalıştırmak
- **Sistem Gereksinimleri** - Minimum ve önerilen sistem özellikleri
- **Kurulum Rehberi** - Detaylı kurulum adımları
- **İlk Adımlar** - Kurulum sonrası ilk yapılacaklar
- **VS Code Kurulumu** - Geliştirme ortamı hazırlığı

## Hedef Kitle

- AykenOS'u ilk kez duyan kullanıcılar
- Sistemi kurmak isteyen geliştiriciler
- Hızlı bir başlangıç yapmak isteyenler
