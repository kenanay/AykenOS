Kullanıcı Alanı (Ring3)

  • Syscall v2 çağrılarını kullanan uygulama/servisler

Çekirdek (Ring0)

Mekanizma katmanı - interrupt, context switch, memory mapping altyapısı ve syscall dispatch.

  • kernel/sys/syscall.c üzerinden INT 0x80 hattı
  • kernel/sys/syscall_v2.h ile ABI kontratı
  • kernel/sched/sched.c ile mekanik ready queue akışı
  • kernel/fs/vfs.c, kernel/fs/devfs.c placeholder/compat katmanı

Boot ve Platform Katmanı

UEFI başlatma ve platform bağlayıcıları - EFI bootloader, kernel yükleme ve QEMU doğrulama akışı.

  • bootloader/efi/BOOTX64.EFI
  • kernel.elf
  • make efi-img ve make run hedefleri

Temel Bileşenler

Syscall v2 Kontratı

Kaynak: kernel/sys/syscall_v2.h, kernel/sys/syscall.c

Sabitler

  • SYS_V2_BASE = 1000
  • SYS_V2_MAX_INDEX = 10
  • SYS_V2_NR = 11
  • SYS_V2_LAST = 1010
# ABI ve dispatcher doğrulama
rg -n "SYS_V2_BASE|SYS_V2_LAST|SYS_V2_NR" kernel/sys/syscall_v2.h
rg -n "valid range: 1000-1010" kernel/sys/syscall.c

Scheduler Runtime Gerçeği

Kaynak: kernel/sched/sched.c

Ring3 policy çağrıları C-call olarak doğrudan çalıştırılamadığı için ilgili hatlar yorum satırına alınmış; aktif seçim akışı kernel ready queue mekanik yolu üzerinden ilerliyor.

rg -n "DISABLED|userspace_scheduler|ready_head" kernel/sched/sched.c

VFS/DevFS Sınırı

Kaynak: kernel/fs/vfs.c, kernel/fs/devfs.c

Ring0 tarafında VFS/DevFS fonksiyonları legacy uyumluluk için minimal placeholder davranışta tutulur; politika tarafı Ring3 hedefinde kalır.

rg -n "placeholder|Ring3 userspace only" kernel/fs/vfs.c kernel/fs/devfs.c

Adım Bileşen Açıklama Kaynak
1 Userspace çağrısı Syscall numarası 1000..1010 aralığında üretilir kernel/sys/syscall_v2.h
