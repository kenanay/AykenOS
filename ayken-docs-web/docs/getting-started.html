AykenOS Hızlı Başlangıç

Bu sayfa, lokal repo durumuna göre güncel teknik başlangıç akışını verir.

AykenOS Nedir?

AykenOS, Ring0 mekanizma / Ring3 politika ayrımını anayasal kurallarla zorlayan bir işletim sistemi çalışmasıdır. Çekirdek tarafında hedef; minimum mekanizma, kullanıcı alanında ise politika ve servis kararlarıdır.

Güncel Teknik Durum (2026-02-21)

  • Faz: Phase 4.5 stabilizasyon/integrasyon
  • ABI: Syscall v2 aralığı sabit 1000..1010 (11 syscall)
  • Dispatcher: kernel/sys/syscall.c yalnızca 1000..1010 kabul eder
  • Runtime Kanıtı: run-20260221T221223Z-3adee991 içinde syscall-v2-runtime PASS, kernel_runtime_verified=true
  • Açık Kalanlar: scheduler bridge ve bazı syscall_v2 TODO alanları

Sistem Gereksinimleri

Temel Araçlar

  • clang, ld.lld, nasm, make
  • qemu-system-x86_64 (runtime test için)
  • Git ve temel shell araçları
  • UEFI boot için img üretim araçları (Makefile üzerinden)

Opsiyonel Araçlar

  • Rust toolchain (userspace runtime geliştirme için)
  • PowerShell (Windows/WSL kurulum scriptleri için)
  • VS Code (editör entegrasyonu için)

Hızlı Kurulum

1

Repository'yi Klonlayın

git clone https://github.com/kenanay/AykenOS.git
cd AykenOS
2

Ortamı Hazırlayın

# Otomatik setup (repo içi script)
make setup

# Gerekirse bağımlılıkları yükle
make install-deps
3

Derleyin

# Kernel + UEFI bootloader
make all

# EFI image
make efi-img
4

Doğrulayın

# Toolchain + build + qemu doğrulaması
make validate

# Sadece runtime kapı doğrulaması
make ci-gate-syscall-v2-runtime

Freeze ve Anayasal Kapılar

AykenOS geliştirme akışında kalite denetimi scripts/ci/* ve Makefile kapıları ile yürür. Özellikle Phase 4.5 stabilizasyonunda aşağıdaki komutlar temel pratik akıştır.

Önerilen Yerel Akış

# Çalışma ağacını hijyen açısından denetle
make ci-gate-hygiene

# ABI kontratını denetle
make ci-gate-abi

# Runtime kontratını denetle
make ci-gate-syscall-v2-runtime

# Yerel freeze zinciri (perf/tooling-isolation hariç)
make ci-freeze-local
Not: Evidence çıktıları evidence/run-<RUN_ID>/ altında üretilir ve kapı raporları bu dizinden takip edilir.

Temel Kavramlar

Syscall v2 Kontratı

Kullanıcı alanı syscall numaraları 1000..1010 aralığında sabittir. Dispatcher bu aralık dışını -ENOSYS döndürerek reddeder.

# ABI başlıklarını hızlı kontrol
rg -n "SYS_V2_BASE|SYS_V2_LAST|SYS_V2_NR" kernel/sys/syscall_v2.h
rg -n "1000..1010|valid range" kernel/sys/syscall.c

Ring0 / Ring3 Ayrımı

Politika kararları Ring3'e taşınır; Ring0 mekanizma yürütür. Scheduler ve VFS/DevFS tarafında bu ayrım aktif olarak korunur.

rg -n "Ring3|placeholder|TODO|DISABLED" \
  kernel/sched/sched.c kernel/fs/vfs.c kernel/fs/devfs.c

Evidence-First Yaklaşımı

Durum iddiaları tek dosya yerine evidence run çıktılarıyla doğrulanır. Raporlar kapı bazlı JSON/TXT olarak üretilir.

# Son run özetini görüntüle
cat evidence/run-20260221T221223Z-3adee991/reports/summary.json

# Runtime gate raporu
cat evidence/run-20260221T221223Z-3adee991/gates/syscall-v2-runtime/report.json

VS Code Entegrasyonu

Depodaki dokümantasyon ve CI scriptleri ile birlikte VS Code kullanırken en kritik nokta, değişikliklerden sonra hızlı gate döngüsünü çalıştırmaktır.

Pratik Komut Seti

make all
make ci-gate-hygiene
make ci-gate-syscall-v2-runtime
