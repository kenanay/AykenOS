AykenOS Hızlı Başlangıç

AykenOS ile ilk adımlarınızı atın ve anayasal işletim sistemi felsefesini keşfedin.

AykenOS Nedir?

AykenOS, anayasal yönetişim, determinizm ve Türk felsefesi ilkeleri üzerine inşa edilmiş yeni nesil bir işletim sistemidir. Geleneksel işletim sistemlerinden farklı olarak, her kod satırı anayasal kurallara tabi olup, mimari bütünlük sürekli korunur.

Temel Felsefe

  • "İstisna = bilinçli karar" - Her istisna gerekçelendirilmeli
  • "İyi mimari → istisnasız mimaridir" - Hedef temiz kod
  • "Tek snapshot yalan söyler. Trend asla yalan söylemez." - Sürekli izleme

Sistem Gereksinimleri

Donanım

  • x86_64 veya ARM64 işlemci
  • Minimum 4GB RAM
  • 20GB disk alanı
  • UEFI desteği

Geliştirme Ortamı

  • Rust 1.70+ (stable)
  • QEMU (test için)
  • GNU Binutils
  • VS Code (önerilen)

Hızlı Kurulum

1

Repository'yi Klonlayın

git clone https://github.com/kenanay/AykenOS.git
cd AykenOS
2

Geliştirme Ortamını Hazırlayın

# macOS için
./setup.sh

# Windows WSL için
./setup.ps1
3

Projeyi Derleyin

make build
4

QEMU'da Test Edin

make qemu

Anayasal Sistem ile Tanışma

AykenOS'un en önemli özelliği anayasal kural sistemidir. Bu sistem, kodunuzun mimari kurallara uygunluğunu sürekli denetler.

İlk Anayasal Kontrol

# Mevcut kodun anayasal durumunu kontrol edin
ayken check

# VS Code formatında çıktı alın
ayken check --format vscode

# CI formatında çıktı alın
ayken check --format ci

Mimari Sağlık Skoru

# Projenin mimari sağlık skorunu görüntüleyin
ayken ahs check

# Detaylı rapor alın
ayken ahs report

# Trend analizi yapın
ayken ahts trend

Temel Kavramlar

Allow Attribute

Geçici istisna mekanizması. Anayasal kuralları bilinçli olarak ihlal etmek için kullanılır.

#[ayken::allow(
    rule = "TIME.INSTANT",
                    class = "BenchmarkMeasurementOnly",
                    reason = "Performance ölçümü için gerekli",
                    expires = "P5"
                )]

Waiver Sistemi

Toplu istisna yönetimi için TOML tabanlı sistem. Büyük refaktörler sırasında kullanılır.

[waivers.time_instant_benchmark]
rule = "TIME.INSTANT"
files = ["benches/**/*.rs"]
reason = "Benchmark kodları için gerekli"
expires = "2026-06-01"

Refaktör Önerileri

Sistem, anayasal ihlalleri düzeltmek için otomatik refaktör önerileri sunar.

# Refaktör önerilerini görüntüleyin
ayken arre analyze

# Otomatik düzeltmeleri uygulayın
ayken fix --safe

VS Code Entegrasyonu

AykenOS, VS Code ile tam entegre çalışır ve gerçek zamanlı anayasal denetim sağlar.

Kurulum

# VS Code ayarlarını kopyalayın
cp .vscode/settings.json.template .vscode/settings.json
cp .vscode/tasks.json.template .vscode/tasks.json

Özellikler

  • Gerçek zamanlı anayasal ihlal tespiti
  • Otomatik refaktör önerileri
  • Mimari sağlık skoru gösterimi
  • Quick fix desteği
