# API Referans Dokümantasyonu

Bu bölüm AykenOS'un tüm API'lerinin detaylı referansını içerir.

## İçerik

- **ABDF API** - ABDF format API referansı
- **BCIB API** - BCIB format API referansı
- **Kernel API** - Kernel space API'leri
- **Userspace API** - User space API'leri
- **CLI Komutları** - Command line interface referansı
- **Rust Crates** - Rust crate'lerinin API dokümantasyonu

## API Kategorileri

### Core APIs
- ABDF v0.2 - Meta-container data format
- BCIB v0.2 - Bytecode instruction format

### System APIs
- Memory management
- Process management
- File system operations
- Network operations

### Constitutional APIs
- Rule engine
- Allow/Waiver systems
- Health scoring
- Refactor recommendations

## Hedef Kitle

- API kullanıcıları
- Library geliştiricileri
- Integration developers
