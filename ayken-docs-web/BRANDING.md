## Official Name and Tagline

```

**Türkçe:**

```

### Rationale

The term "Constitutional" is chosen because:

1. **Core to Project DNA**
   - Constitutional governance system
   - Constitutional compliance gates (12 active gates)
   - Constitutional rules (non-negotiable, non-overridable)
   - Constitutional freeze workflow
   - Constitutional surface (Ring0 exports)
   - Constitutional enforcement via CI

2. **Unique Differentiator**
   - No other operating system uses "constitutional" approach
   - Reflects principle-driven governance
   - Emphasizes immutable rules and formal guarantees
   - Conveys reliability and stability

3. **Encompasses All Core Features**
   - ✅ AI-Native (AI integration at core)
   - ✅ Deterministic (constitutional rules guarantee it)
   - ✅ Execution-Centric (constitutional syscall interface)
   - ✅ Evidence-Based (constitutional enforcement)
   - ✅ Ring3 Empowerment (constitutional boundary)

4. **Strong Message**
   - "Constitution" = Immutable rules
   - Reliability and stability
   - Professional and serious tone
   - Legal/governance metaphor resonates

## Key Messages

### Elevator Pitch (30 seconds)

**English:**
"AykenOS is the Constitutional AI Operating System. Unlike traditional operating systems, it's governed by immutable principles enforced through 12 CI gates. With only 11 syscalls, Ring3 empowerment, and deterministic execution, AykenOS reimagines computing for the AI era."

**Türkçe:**
"AykenOS, Anayasal Yapay Zeka İşletim Sistemidir. Geleneksel işletim sistemlerinden farklı olarak, 12 CI kapısı ile zorunlu kılınan değiştirilemez ilkelerle yönetilir. Sadece 11 sistem çağrısı, Ring3 güçlendirmesi ve deterministik yürütme ile AykenOS, yapay zeka çağı için bilişimi yeniden tasarlar."

### Core Value Propositions

1. **Constitutional Governance**
   - Immutable rules enforced by CI
   - Evidence-based development
   - Fail-closed discipline

2. **AI-Native Design**
   - ABDF format for AI/ML data
   - BCIB execution engine
   - Ring3 AI runtime

3. **Deterministic Execution**
   - Reproducible behavior
   - No timing hacks
   - Tick-based regression

4. **Ring3 Empowerment**
   - All policy in userspace
   - Minimal kernel (11 syscalls)
   - Capability-based security

## Prohibited Usage

### Do NOT Use:

❌ "Ayken OS" (with space)  
❌ "AykenOs" (lowercase 's')  
❌ "AYKENOS" (all caps, except in code constants)  
❌ "Ayken Operating System" (too generic)  
❌ "Constitutional OS" (without AykenOS)  

### Always Use:

✅ "AykenOS" (one word, camelCase)  
✅ "The Constitutional AI Operating System" (full tagline)  
✅ "Constitutional AI OS" (abbreviated tagline)
